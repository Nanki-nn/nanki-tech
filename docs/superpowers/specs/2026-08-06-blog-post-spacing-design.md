# 文章正文紧凑排版设计

## 目标

减少文章正文段落和引用块之间重复叠加的空白，让连续阅读更紧凑，同时保留章节、列表和图片之间的层次。

## 设计

- 正文普通段落行高由 `32px` 调整为 `28px`。
- 普通段落底部间距由 `20px` 调整为 `12px`。
- 引用块上下间距由 `28px` 调整为 `16px`。
- 引用块内的直接段落不再追加底部间距，避免父子间距叠加。
- 标题、列表、代码块、图片、表格和分隔线间距保持不变。
- 只修改共享 Markdown 渲染样式，不调整文章原文。

## 验证

1. 连续普通段落之间的可见间距为 `12px`。
2. 普通段落与引用块之间的可见间距为 `16px`。
3. 正文链接、粗体、引用线和目录继续正常渲染。
4. 桌面与移动宽度下无文字重叠或横向溢出。
5. 类型检查不新增错误。
