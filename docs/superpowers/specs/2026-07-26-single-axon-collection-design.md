# 单一 Axon 合集设计

## 目标

Blog 页的“精选合集”区域只保留一个 Axon 有序系列，并在中文和英文界面中显示完全相同的中文专题内容。专题标题统一为“Axon：从 0 到 1 实现一个 Agent”，卡片保持现有半栏宽度。

## 数据调整

- `content_zh/collections.toml` 与 `content/collections.toml` 均只保留 `axon-tutorial`。
- 删除两份配置中的 `agent-engineering` 专题，避免隐藏后仍可通过旧地址访问重复合集。
- 两份 Axon 合集配置使用相同的中文标题、描述、类型、排序和 11 篇文章 slug。
- 英文博客清单补齐这 11 篇 Axon 文章的中文元数据，使英文界面解析出的合集文章数量、顺序、标题和摘要与中文界面一致。
- 文章正文继续复用默认中文内容目录，不复制 Markdown 文件，也不新增翻译稿。

## 页面行为

- 中文和英文 Blog 页的精选合集区都只渲染一张 Axon 卡片。
- 单卡继续使用现有两列网格的一个单元格，因此桌面端保持半栏宽度，移动端仍按现有规则占满可用宽度。
- 合集详情页在两种语言下都显示同一组 11 篇中文文章。
- 界面级标签继续跟随当前语言，例如 `有序系列` / `Series`、`篇文章` / `articles`；专题标题、描述和文章内容保持中文一致。
- 普通 Blog 时间线仍由各语言的博客清单生成；英文清单补齐的 Axon 条目会在英文时间线中显示，以保证从合集进入和从时间线进入时内容一致。

## 不改动范围

- 不修改 `CollectionShelf`、`CollectionPageClient` 或网格样式。
- 不改变合集 slug `axon-tutorial`，现有链接继续有效。
- 不新增英文翻译，不复制中文 Markdown 文件。
- 不调整 Axon 之外的文章内容。

## 验证

1. 运行类型检查或生产构建，确认 TOML 配置可解析且静态页面可生成。
2. 检查中文和英文 Blog 页均只有一个半栏 Axon 卡片，标题为“Axon：从 0 到 1 实现一个 Agent”，文章数为 11。
3. 打开两种语言下的 `/blog/collections/axon-tutorial`，确认文章顺序、标题、摘要和链接一致。
4. 确认 `/blog/collections/agent-engineering` 不再生成，且普通 Blog 时间线正常显示。
