# Blog 列表辅助标签精简设计

## 目标

移除 Blog 页面截图中标出的辅助标签，让合集卡片和文章时间线更简洁。

## 设计

- 合集卡片不再显示“有序系列 / 主题专题”和文章篇数，右上角合集编号继续保留。
- 文章列表不再显示 `subtitle` 分类文字，只保留日期、标题和摘要。
- 在共享列表内容组件中处理文章分类，因此 Blog 时间线与合集文章列表保持一致。
- 数据配置保持不变，文章详情页、合集详情页头部和页面元信息不受影响。

## 验证

1. Blog 合集卡片不显示类型和篇数。
2. Blog 时间线不显示 `AI Agent Engineering`、`AI Notes` 或 `Axon Tutorial`。
3. 日期、标题、摘要、合集编号和链接仍正常显示。
4. 桌面与移动宽度下布局无重叠或横向溢出。
