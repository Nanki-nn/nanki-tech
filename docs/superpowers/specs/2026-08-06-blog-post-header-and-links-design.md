# 文章详情页精简与链接样式设计

## 目标

精简所有博客文章详情页的头部信息，并让正文超链接在浅色和深色主题下都能被快速识别。

## 设计

- 文章详情页头部保留副标题、日期和标题。
- 不再在详情页头部渲染 `post.content` 摘要和 `post.tags` 标签。
- 摘要和标签数据继续保留，博客列表与页面元信息仍可使用这些字段。
- 为 React Markdown 的 `a` 元素增加统一样式：强调色、下划线、下划线偏移和悬停反馈。
- 链接内的粗体或行内代码继承链接颜色，避免链接文字被子元素样式覆盖。
- 返回博客列表的导航链接不属于正文 Markdown，保持现有样式。

## 验证

1. 任意文章详情页的头部不再显示摘要和标签。
2. 博客列表仍显示已有摘要，页面描述元信息仍使用 `post.content`。
3. 普通链接、粗体链接和引用中的链接均有清晰的强调色与下划线。
4. 浅色和深色主题下链接均可辨识，悬停状态正常。
5. 类型检查或生产构建不新增错误。
