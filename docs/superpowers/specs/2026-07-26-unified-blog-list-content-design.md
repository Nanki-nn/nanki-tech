# Blog 列表内容一致性设计

## 目标

Blog 时间线与 Axon 合集页的文章列表展示同一组核心字段，并移除截图标出的标签和“Read / 阅读文章”入口。

## 统一字段

两个列表中的每篇文章都按相同顺序展示已有字段：

1. 副标题和日期；
2. 文章标题；
3. 文章摘要，即 `post.content`。

副标题、日期或摘要为空时直接省略对应行，不添加占位文案，也不修改文章数据。

标签不再出现在这两个列表中。“Read / 阅读文章”文字入口和右上箭头也不再出现。文章正文页中的标签不属于本次范围，继续保留。

## 实现方式

- 新增一个共享的文章列表内容组件，统一渲染副标题、日期、标题与摘要；可选字段只在有值时渲染。
- `BlogTimeline` 使用共享组件，并由共享组件在这个场景中渲染标题链接。
- `CollectionPageClient` 使用共享组件，仍由外层 `Link` 提供整项可点击行为；共享组件在这个场景中不得再生成标题链接，避免嵌套锚点。
- 删除两个列表组件中不再使用的标签渲染、阅读文案和 `ArrowUpRight` 图标。
- 两边现有的年份列、系列序号列、边框、时间轴标记、列表包装结构和响应式断点保持不变。
- 不修改文章数据配置，不改变合集顺序或文章路由。

## 验证

1. Blog 时间线与 Axon 合集页都按相同顺序显示已有的副标题、日期、标题和 `post.content` 摘要；空字段不显示占位内容。
2. 两个列表都不显示标签、`Read`、`阅读文章`或对应箭头。
3. Blog 时间线标题链接与合集页整项链接仍能打开文章。
4. 检查渲染结构，确认两个列表都不存在嵌套锚点。
5. 桌面和移动宽度下，年份列、系列序号列、边框、时间轴标记、包装结构和响应式断点保持原样，且与文本不重叠。
6. 生产构建通过。
